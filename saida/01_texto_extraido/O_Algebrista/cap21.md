A igualdade em álgebra possui dois significados diferentes. Considerando duas expressões 
algébricas, podemos ter: 

a) Iguais, somente para determinados valores 
Exemplo: x+5x+4=0 

Esta expressão nem sempre é verdadeira. É correta apenas quando x=1 ou x=4, Esta expressão 

é uma equação, e é válida apenas quando x assume um desses valores, que são chamados 
raízes da equação. 

b) Iguais, quaisquer que sejam os valores 

Exemplo: (x + 1)2=x²+9x +11 

Esta expressão é sempre verdadeira, ou seja, é correta para qualquer valor de x. Este tipo de 
expressão é chamada de identidade. Apesar de ser usado o mesmo símbolo de igualdade, seu 
significado é diferente. Diz-se no caso (b) que as duas expressões nos membros da igualdade 
são não apenas iguais, mas sim, idênticas, ou identicamente iguais. Pode ser usado o símbolo = 
para indicar quantidades identicamente iguais, ou seja, iguais para qualquer valor de x ou 
demais incógnitas.

Tx) = (x) : Igualdade ou equação: São expressões algebricamente diferentes, mas que para 
Buns valores de x podem assumir valores iguais, apesar de suas fórmulas serem diferentes.
