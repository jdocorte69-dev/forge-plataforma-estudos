## Folha de cola (1–2 páginas)

| Tema | Fórmula-central | Armadilha |
| --- | --- | --- |
| Conjuntos Numericos | Encadeamento: ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ. | Confundir 'pertencer' com 'ser subconjunto'. |
| Equacoes | Fórmula de Bháskara: x = (−b ± √Δ)/(2a), com Δ = b² − 4ac. | Fazer 'passar para o outro lado trocando sinal' sem entender |
| Matrizes | det(AB) = det(A)·det(B). | Multiplicar matrizes 'elemento por elemento' como se fosse s |
| Operacoes Inteiros | aᵐ · aⁿ = aᵐ⁺ⁿ; aᵐ / aⁿ = aᵐ⁻ⁿ; (aᵐ)ⁿ = aᵐⁿ. | Trocar |−6| por −6. |
| Produtos Notaveis | (a + b)² = a² + 2ab + b²; (a − b)² = a² − 2ab + b². | Escrever a² + b² = (a+b)² — falta o termo 2ab. |
