## Gabarito comentado

1. 459 — (22+5)(22−5) = 22² − 5² = 484 − 25 = 459.

2. (x + 0)(x − 4) — Procuramos dois números com soma -4 e produto +0: 0 e -4. Logo x*(x - 4).

3. x = -4 ou x = 4 — Soma 0 = 0 e produto -16 = -16; Δ = 64 = 64.

4. x = -2 ou x = 4 — Soma 2 = 2 e produto -8 = -8; Δ = 36 = 36.

5. 16/5 — y = 5x + (+3) ⇒ x = (y − (+3))/5; com y = 19, x = 16/5.

6. 2 — Pela definição, log_2(4) = 2 porque 2^2 = 4.

7. √3/2 — No círculo unitário, cos(30°) = √3/2; confira com sen²+cos² = 1.

8. -4 — det = 2×-2 − -2×0 = -4 − (0) = -4.

9. 840 — A ordem importa; A(7,4) = 840.

10. 0.7000 — P(A∪B) = 0.60 + 0.20 − 0.1000 = 0.7000.

11. 0.6800 — P(A∪B) = 0.40 + 0.40 − 0.1200 = 0.6800.

12. 123 cm — h² = 27² + 120² = 729 + 14400 = 15129 ⇒ h = 123 cm.

13. 144 cm³ — V = a·b·c = 6×8×3 = 144 cm³.

14. (-1,2) — M = ((-3+(1))/2, (5+(-1))/2) = (-1,2).

15. 49 — aₙ = a₁ + (n−1)r = 7 + 14×3 = 49.

16. 8 — (x² − 16) = (x−4)(x+4); cancelando, sobra x+4 ⇒ limite 8.

17. 48 — f′(x) = 3x^2; f′(4) = 3×4^2 = 48.

18. 1/3 — Primitiva: x^3/3; de 0 a 1 dá 1/3 = 1/3.

19. 1/2 — Primitiva: x^2/2; de 0 a 1 dá 1/2 = 1/2.

20. média 11.80; mediana 9 — Média = 59/5 = 11.80; ordenados: [6, 7, 9, 17, 20] ⇒ mediana 9.
