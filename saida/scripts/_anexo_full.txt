 Aula 3.1: Arquiteturas Von Neumann vs. Harvard 
 ●  Problema Real:  Como organizar os componentes de memória  e processamento

 ●  Impasse:  Compartilhar o mesmo barramento físico para  dados e instruções

 ●  Salto de Intuição:  Separar fisicamente a memória e  os barramentos de 
 instruções e dados Arquitetura Harvard) ou usar Caches L1 separadas 
 mantendo memória principal unificada Arquitetura Harvard Modificada). 
 ●  Formalização: 
 ○  Von Neumann: 1 Barramento de Dados/  Instrução, 1 Memória Unificada. 
 ○  Harvard: Barramento de Instrução PC $  \rightarrow$ Memory Code) + 
 Barramento de Dados ALU $  \leftrightarrow$ Memory Data). 
 ●  Teste de Feynman:  Explique como as CPUs modernas combinam  o modelo Von 
 Neumann na memória RAM com o modelo Harvard nas Caches L1.

 Aula 3.3: O Ciclo Clássico Fetch-  Decode-  Execute 
 ●  Problema Real:  De que maneira um circuito estático  consegue interpretar
